# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in NebulaCompute, please report it responsibly:

1. **Do NOT** open a public GitHub issue for security vulnerabilities
2. Email the security team at: security@nebulacompute.io
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Any suggested fixes (optional)

## Response Timeline

- **Initial Response**: Within 48 hours
- **Status Update**: Within 7 days
- **Resolution**: Depends on severity (critical: 7-14 days, high: 30 days, medium/low: 90 days)

## Security Best Practices

When using NebulaCompute:

1. Keep all dependencies updated
2. Use strong authentication tokens
3. Run workers in isolated environments
4. Enable TLS for all network communications
5. Follow the principle of least privilege
6. Regularly audit access logs

## Disclosure Policy

We follow responsible disclosure practices and will credit reporters in our release notes (unless anonymity is requested).
